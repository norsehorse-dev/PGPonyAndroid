Everything reported in this thread should be fixed in it. Please try it and tell me what is still wrong, I would much rather hear it now than after it is published. It reports as 4.1.0-rc2 in Settings → About, so we can both be certain which build you are on.

If you installed PGPony from F-Droid, read this before downloading. F-Droid signs its builds with its own key, so Android will refuse to install this one over it. Getting it would mean uninstalling first, and uninstalling deletes your keyring. If you want to try the build, back up first — Settings → Backup — and keep the recovery code somewhere you can actually find it. If that is more trouble than it is worth, that is a completely fair answer: wait for the F-Droid release, and say so here so I know you are waiting.

If you installed from pgpony.app or GitHub, it upgrades in place and your keys stay where they are.
