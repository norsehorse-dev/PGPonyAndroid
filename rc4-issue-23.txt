This is fixed. Thank you for reporting it.

The Generate Key screen could not scroll. On phones where the form is slightly taller than the screen, the Passphrase fields and the Generate button were below the bottom edge with no way to reach them. Samsung phones were affected most, because the system font is wider than the one the layout was tested with.

The fix is in 4.1.0, which is not released yet. You can install the test build now:

https://pgpony.app/rc/4.1.0-rc2/PGPony-4.1.0-rc2.apk

If you installed PGPony from F-Droid, please do not install this over it. F-Droid signs its builds with a different key, so Android will ask you to uninstall first, and uninstalling deletes your keys. Back up first in Settings, Backup.

Please tell me if you can create a key now. It would also help to know which phone you have, and whether you use a large font size in your phone settings.
