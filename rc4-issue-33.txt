Confirmed, and thank you, the repro is exactly right and it reproduces for
the reason you'd hope it doesn't: text decrypt and file decrypt take
different paths through the crypto layer, and the post-quantum branch was
only ever wired into the text path. File decrypt streams from disk and
never learned it. That is why v5 and v6 both fail, and why Windows fails
the same way, since it shares the same file.

Two things worth saying plainly. Your files are not damaged; the encryption
side is correct, and they will open as soon as the file path gets the same
branch the text path has. And this is not the ecosystem limitation some of
the PQC caveats describe; it is our bug, and it is fixable.

Fix is scheduled for the next patch release. I will post here when a build
is up.

The file-decrypt bug you reported is fixed. A file encrypted to a PGPony ML-KEM key (v5 or v6) wouldn't open in PGPony itself, on Android or Windows: post-quantum decrypt was wired into the text path but not the file path, so BouncyCastle hit the unknown algorithm and threw before PGPony's own code ran. Fixed now, with a regression test so it can't come back quietly.

You also asked about Windows. Same code, same bug, and it's fixed there too. That fix ships in PGPonyDesktop v2.0.0, which is almost finished. Watch github.com/norsehorse-dev/PGPonyDesktop or https://pgpony.app/desktop for it.

The Android build below isn't the finished 4.2.0. I'm still building the rest, but I wanted to get this fix to you now. One caveat: a very large PQC file (well over 100 MB) can still hit a memory limit for now, a streaming fix is part of the 4.2.0 work still to come. Ordinary files are fine.

Build, the foss APK (no Google dependencies):
https://pgpony.app/rc/4.2.0-RC1/PGPony-4.2.0-RC1-foss.apk

Signature and SHA-256:
https://pgpony.app/rc/4.2.0-RC1/PGPony-4.2.0-RC1-foss.apk.asc
https://pgpony.app/rc/4.2.0-RC1/PGPony-4.2.0-RC1-foss.apk.sha256

This build is signed with my key, same as the pgpony.app download. If you installed from F-Droid or Google Play, their signatures differ and Android won't update over it: back up your keyring (Settings), uninstall, install this, then restore. On the pgpony.app build it updates in place.

Thanks for the report.
